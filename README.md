# Habit Tracker Dashboard — Interactive Daily Tracker

🖼️ Interactive Habit Tracker Interface

A sleek, responsive, and aesthetic daily habit dashboard built using pure HTML5 and custom CSS3. This project focuses on modern UI layout design, component structuring, clean visual hierarchy, and dashboard card styling.

---

✨ Key Features

* **Modern Pastel UI:** Designed with soft color palettes, clean typography, rounded card borders, and structured dashboard panels using pure CSS.
* **Progress & Metrics Display:** Features circular progress chart, highlight badges, and status summary cards for quick daily habit overview.
* **Custom Table & List Components:** Integrated styled tables with icon integration for habit items, counts, and completion tracking.

---

🛠️ Built With

* **HTML5** (Semantic layout structure & table markup)
* **CSS3** (custom border-radius, pastel color styling, and UI layout)
* **Git & GitHub** (Version control and deployment)

---

💡 What I Learned

Through this project, I strengthened my understanding of converting complex visual dashboard concepts into clean web pages using pure CSS, structuring uniform dashboard cards, and styling clean structured tables and metric indicators without relying on external CSS frameworks.
